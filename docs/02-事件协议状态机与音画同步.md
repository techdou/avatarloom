# 事件协议、状态机与音画同步

## Event Envelope

```json
{
  "id": "evt_xxx",
  "type": "transcript.completed",
  "session_id": "ses_xxx",
  "run_id": "run_xxx",
  "timestamp": 0,
  "source": "stt.sensevoice",
  "sequence": 1,
  "payload": {}
}
```

核心事件包括 session、audio、speech、transcript、llm、tts、avatar、vision、persona、response、block、run 和 artifact。

## 显式状态机

```text
IDLE
LISTENING
TRANSCRIBING
THINKING
SPEAKING
INTERRUPTING
ERROR
CLOSED
```

用户在 SPEAKING 状态开口时：取消 LLM、取消 TTS、清空音频、清空 Speech Frame、重置 Avatar，然后进入 LISTENING。

## 音画同步

- 音频是主时钟。
- Speech Frame 按音频播放位置消费。
- Idle Frame 直接显示，不进入口型队列。
- 视频落后时允许跳帧。
- 视频生成慢不得阻塞音频。
- 打断时清空音频和 Speech Frame。
- Avatar 不可用时自动回退 StaticAvatar。

建议配置：

```yaml
sync:
  audioDelayMs: 600
  videoLagFrames: 0
  maxVideoBehindMs: 1000
  dropPolicy: drop_oldest_video
```

Debug Overlay 应显示音频缓冲、视频队列、FPS、解码耗时、音频位置和帧序号。
